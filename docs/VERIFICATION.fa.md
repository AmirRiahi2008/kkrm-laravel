# بررسی رفتار نسخهٔ Blade

## مسیرها و محتوای فارسی

کنترلر صفحات عمومی پیش از جستجوی slug از Request::decodedPath استفاده می‌کند. مسیر فارسی خبر، مقاله و آلبوم به شکل صحیح تفسیر می‌شود. پیشوند انگلیسی فقط در مرز یک بخش مسیر حذف می‌شود؛ برای نمونه نام صفحه‌ای که صرفاً با en شروع می‌شود تغییر نمی‌کند.

بررسی syntax PHP و شش نمونهٔ مسیر فارسی، انگلیسی و پیشوند زبان موفق بود. نمونه‌های واقعی جزئیات خبر، مقاله و آلبوم پس از این اصلاح پاسخ 200 داشتند.

## بررسی رابط و پاسخ‌ها

صفحهٔ اصلی، فرم ورود، نسخهٔ انگلیسی، آرشیو کارشناسان و اسناد، محاسبه‌گر، سامانه‌ها، تماس، پرسش‌های متداول و دانلود بررسی شدند. فایل‌های CSS و JS، تصویر عمومی و manifest قابل دریافت بودند. دو تصویر آلبوم بارگذاری شدند و نمایشگر تصویر بزرگ از object-fit: contain استفاده می‌کند.

API کاربر جاری و مدیریت محتوا بدون ورود پاسخ 401 دارند. این بررسی به معنی ورود با حساب مدیر واقعی یا انجام CRUD روی دادهٔ واقعی نیست.

## بررسی مستقل برنامه

پیش از استقرار، ۵۵ بررسی یکپارچه با PHP، MySQL مستقل و دیسک local انجام شد. این بررسی‌ها ورود، دریافت API مدیریت بدون Origin و Referer، CSRF، انقضای نشست، دو آپلود پیاپی، فایل عمومی و خصوصی، cache مسیرها و تولید لینک دامنهٔ عمومی را پوشش دادند.

داده و ابزار بررسی خارج از پروژه قرار دارند؛ فایل تستی همراه برنامه تحویل داده نشده است. این نتایج به معنی بررسی تک‌تک محتوای پایگاه داده یا همهٔ لینک‌های خارجی نیست.

## تفاوت سورس و نسخهٔ نصب‌شده

حذف src خالیِ تصویر نمایشگر گالری در سورس آماده است. این بهبود هنگام ثبت گزارش هنوز روی هاست نصب نشده بود. برای همگام شدن نسخهٔ نصب‌شده، فایل resources/views/layouts/base.blade.php از همین سورس منتقل شود. تغییر سورس در GitHub به‌تنهایی فایل‌های PHP میزبان را جایگزین نمی‌کند.
